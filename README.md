# Liora Ortaca

Statik, Vercel uyumlu proje tanıtım sitesi. Herhangi bir build adımı gerektirmez; GitHub'a gönderdikten sonra Vercel'de **Other** framework preset'iyle doğrudan deploy edilebilir.

Yayına almadan önce `script.js` içindeki `whatsappNumber` değerini kurumsal WhatsApp numarasıyla ve `index.html` içindeki telefon/e-posta bilgilerini gerçek iletişim bilgilerinizle değiştirin.
